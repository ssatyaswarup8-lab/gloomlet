# Gloomlet — project submission draft

## Project name
Gloomlet — Meet Pip, Your Tiny Dream Engineer

## Short description
Gloomlet is a character-driven portfolio that turns a conventional project showcase into a cozy, interactive dream world. Visitors can discover Pip’s story, explore projects, travel through a Dreamscape, compose browser-generated lullabies, leave a guestbook message, and look for a hidden Easter egg.

## What makes it different
- A consistent character and story-led visual identity.
- Interactive navigation and exploration rather than a static portfolio layout.
- A Lullaby Lab built around browser audio controls.
- Visitor participation through the guestbook and hidden surprise.
